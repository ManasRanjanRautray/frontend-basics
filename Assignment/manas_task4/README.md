# Task 4 - CSS Units, Box Model, Fonts

## 📌 Objective
This assignment demonstrates:
- Viewport units (vw, vh)
- CSS Box Model
- Fonts and styling

---

## 📂 Files
- index.html
- style.css
- README.md

---

## ✅ Features

### 1. Viewport Units
- Used vw for width and horizontal spacing
- Used vh for height and vertical spacing

### 2. Layout Rules
- 25vw margin on left and right
- 10vh margin on top and bottom
- No scrolling

### 3. Box Model
- Border, padding applied to image container
- box-sizing: border-box used

### 4. Semantic HTML
- Used `<button>` instead of `<div>`

### 5. Fonts
- Google Font (Poppins) used
